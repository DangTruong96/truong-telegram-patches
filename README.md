# Bản vá Morphe cho Telegram (bản cá nhân)

Bundle `.mpp` dựng sẵn cho Morphe Manager. Hỗ trợ Telegram 13.1.0 (org.telegram.messenger / org.telegram.messenger.web).

Thêm vào Morphe Manager: https://morphe.software/add-source?github=DangTruong96/truong-telegram-patches

Nguồn gốc: HushTelegram by SysAdminDoc (GPL-3.0) + bản dịch tiếng Việt cho phần cài đặt, patch Giờ yên lặng, lưu file theo thư mục từng chat, gói Quiet Pack, mặc định yên tĩnh cá nhân hoá. Chỉ dùng cá nhân.

Lưu ý: APK vá bằng Morphe Manager được ký bằng keystore trong Manager của bạn; APK vá sẵn do chủ repo gửi riêng được ký bằng keystore khác — với mỗi app, hãy chọn một đường và dùng nhất quán để các bản cập nhật cài đè được lên nhau.
