# Changelog

## 2026-10-25 — Edit history (bundle 0.0.20)
- New patch "Edit history": Telegram silently re-reads a message right before it is edited — this patch captures that earlier text and keeps a local history per message. Long-press a message and choose the history entry to see what changed. On by default; history is stored only on your device.
- All 68 patches from the previous build are unchanged (69 patches in total).

## 2026-10-24 — Quiet pack update (bundle 0.0.20)
- Full Vietnamese settings (707 strings).
- Quiet hours: notifications stay silent inside a window you choose (22:00–07:00 by default); Telegram service messages and Saved Messages still make their sound.
- Save downloaded files can file each chat into its own folder.
- Quiet pack preset turns the quiet/privacy switches on in one tap.
- The quiet defaults now start on: silence non-contacts, hide phone number stays off.

## 2026-10-24 — First release (bundle 0.0.20)
- HushTelegram patches for Telegram 13.1.0: hide ads and upsells, hide stories, keep deleted messages, faster downloads, AMOLED and more (67 patches).
